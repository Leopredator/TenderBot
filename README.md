# TenderBot

**Мониторинг тендерных площадок с push-уведомлениями в Telegram.**

Каждые 30 минут (настраивается) сервис обходит тендерные площадки, находит свежие закупки, отфильтровывает их по вашим ключевым словам, городам и заказчикам — и присылает уведомление в Telegram.

## Возможности

- 🔄 **Автоматический мониторинг** — обход площадок по расписанию, без ручного поиска.
- 🔎 **Умные фильтры** — ключевые слова с учётом русской морфологии («компьютерам» = «компьютер»), города и регионы по фрагменту названия, заказчики.
- 📲 **Push в Telegram** — уведомление приходит сразу после обнаружения тендера.
- 🗂 **История в SQLite** — все найденные тендеры сохраняются, по ним работает поиск (`/search`).
- 🧭 **Управление прямо из чата** — постоянная клавиатура с кнопками: «Актуальное», «Статистика», «Категории», «Города».
- 🧱 **Модульная архитектура** — сбор данных, фильтрация и рассылка разнесены по слоям, парсеры подключаются независимо.

## Источники данных

| Источник | Что покрывает |
|---|---|
| **[zakupki.gov.ru](https://zakupki.gov.ru) (ЕИС)** | официальный портал госзакупок, 44-ФЗ и 223-ФЗ |
| **[rostender.info](https://rostender.info)** | агрегатор: тендеры ЕИС и коммерческих площадок (B2B-Center, Росэлторг, РТС-тендер, Сбер-А, ЭТП ГПБ и др.) |

### Ограничения площадок

- `rostender.info` прячет имя заказчика от анонимных посетителей — фильтр по заказчикам работает для тендеров ЕИС (у них заказчик публичен).
- ЕИС иногда показывает капчу или недоступен из-за рубежа — такой цикл просто пропускается, остальные источники продолжают работать.

## Установка

1. Установите **Python 3.10+** (проверка: `py -3 --version`).

2. Создайте бота в Telegram: найдите **@BotFather**, отправьте `/newbot` и получите **токен** вида `123456789:AA...`.

3. Скопируйте `.env.example` в созданный `.env` и впишите токен:

   ```ini
   TELEGRAM_BOT_TOKEN=123456789:AA...
   ```

4. Запустите `start.bat` — он создаст виртуальное окружение, установит зависимости и запустит сервис.

   Либо вручную:

   ```bat
   py -3 -m venv .venv
   .venv\Scripts\python -m pip install -r requirements.txt
   .venv\Scripts\python run.py
   ```

5. В Telegram напишите своему боту `/start` — он покажет кнопки меню и начнёт присылать уведомления в этот чат.

## Кнопки меню

Под полем ввода — постоянная клавиатура:

| Кнопка | Что делает |
|---|---|
| **Актуальное** | собирает с площадок все подходящие тендеры прямо сейчас (и новые, и уже опубликованные) |
| **Статистика** | счётчики по базе и фильтрам |
| **Категории** | категории (отрасли), найденные в собранных тендерах — нажатие добавляет их в фильтры |
| **Города** | список активных городов/регионов, у каждого кнопка «Убрать» |

## Команды бота

| Команда | Действие |
|---|---|
| `/start` | подключить чат к уведомлениям (показывает кнопки) |
| `/menu` | показать кнопки снова |
| `/add_word поставка компьютеров` | добавить ключевое слово (морфология учитывается) |
| `/del_word поставка компьютеров` | убрать ключевое слово |
| `/add_city Москва` | фильтр по городу или региону (по фрагменту: «приморск» найдёт «Приморский край») |
| `/del_city Москва` | убрать город |
| `/add_customer РЖД` | следить за заказчиком (работает по ЕИС) |
| `/del_customer РЖД` | перестать следить |
| `/categories` | категории из собранных тендеров (кнопки) |
| `/cities` | список городов с кнопками удаления |
| `/list` | показать все активные фильтры |
| `/fresh` | все подходящие тендеры на площадках прямо сейчас |
| `/search ноутбук` | поиск по сохранённой истории тендеров |
| `/pause` · `/resume` | приостановить / возобновить уведомления |
| `/stats` | статистика |
| `/help` | справка |

## Настройки (.env)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | токен бота (**обязательно**) |
| `SCAN_INTERVAL_MIN` | `30` | как часто проверять площадки, мин |
| `MAX_PAGES_PER_SCAN` | `2` | страниц на проход (~20 тендеров/стр. на rostender, ~50 на ЕИС) |
| `ENABLED_SOURCES` | `rostender,eis` | включённые источники |
| `TELEGRAM_REAL_IP` | `149.154.167.220,149.154.175.50,91.108.56.170` | IP `api.telegram.org` для обхода DNS-блокировки (пусто — обычный DNS) |

## Решение проблем

### Бот не запускается: `WinError 121`, таймаут `api.telegram.org`

Некоторые провайдеры подменяют DNS-ответы для `api.telegram.org` на фейковые адреса. TenderBot по умолчанию подключается к Telegram по закреплённым официальным IP — это безопасно, адреса Telegram стабильны.

Если Telegram у вас недоступен в принципе (нужен прокси) — потребуется прокси-настройка, её пока нет.

### Тендеры с rostender приходят без заказчика

Так и должно быть: площадка скрывает заказчика от анонимных посетителей. Фильтр по заказчикам применяйте к тендерам ЕИС.

### Цикл сканирования пропущен

Обычно это капча или недоступность ЕИС. Сервис продолжит работу и попробует снова на следующем цикле.

## Автозапуск при старте Windows

**Планировщик заданий** → *Создать задачу* → **Триггер:** «При входе в систему» → **Действие:** запуск `G:\TenderBot\start.bat` (или `.venv\Scripts\python.exe run.py` относительно папки проекта).

Уведомления приходят, пока работает сервис — то есть пока компьютер включён.

## Структура проекта

```text
run.py                    — точка входа (бот + сканер)
start.bat                 — быстрый запуск на Windows
tenderbot/
  bot.py                  — команды Telegram-бота
  scanner.py              — периодический сбор и рассылка
  storage.py              — SQLite (чаты, фильтры, история тендеров)
  filters.py              — морфологическая фильтрация (русский стеммер)
  config.py               — чтение .env
  sources/
    rostender.py          — парсер rostender.info
    eis.py                — парсер zakupki.gov.ru
tenderbot.db              — база данных (создаётся автоматически)
```
